# Chapter13 Log File Analyzer

This repository contains a C++ implementation of a log file analyzer (Chapter 13).

## Description

A small C++ project for analyzing and processing log files. The codebase uses CMake for building.

## Requirements

- C++17 compatible compiler (e.g. g++, clang++)
- CMake 3.10+

## Build

```bash
mkdir build
cd build
cmake ..
cmake --build .
```

This will generate the executable(s) in the build directory.

## Usage

Run the produced binary with the path to a log file as an argument. Example:

```bash
./LogFileAnalyzer /path/to/logfile.log
```

Replace `LogFileAnalyzer` with the actual executable name produced by the build.
